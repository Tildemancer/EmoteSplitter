Emote Splitter for Final Fantasy.

Up to 32k bytes of text in the editbox split into 500 byte chunks. You can cancel on any chunk or keep posting.

Continuation markers:
#c for current chunk.
#m for max chunks.
#r for remaining chunks.
Or anything else you set. I like [FIN], like a movie.

Manual breaks:
|n is a raw break.
|nn is a break with no markers.
|nb is a break with no markers, but not counted toward #m till it posts.
|n# is a break with a # second delay.
